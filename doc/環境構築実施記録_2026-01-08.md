## 4. 注意事項・既知の問題

### ⚠️ librosaがインストールされていない

**原因**: `librosa`の依存関係である`numba`→`llvmlite`のビルドに失敗

```
CMake Error: LLVM CMake export states LLVM version is 14, 
llvmlite only officially supports 20.
```

**影響**: 
- 現在のアナライザー（danceability, energy, key）は**essentia**ベースのため、**動作に影響なし**
- 将来的にlibrosaを使用する機能を追加する場合は対応が必要

**対処法**（必要になった場合）:
```bash
# conda環境を使用する方法
conda install -c conda-forge librosa

# または、ビルド済みホイールを探す
pip install --only-binary :all: librosa
```

### ⚠️ Python 3.9 → 3.12 への変更

手順書の前提条件は「Python 3.10以上」でしたが、システムデフォルトはPython 3.9でした。
Homebrew経由でPython 3.12をインストールし、仮想環境を再作成しました。

### ⚠️ demucs（音源分離）は未インストール

`requirements.txt`に含まれていますが、約2GBの重量級パッケージのため、
必要になるまでスキップしています。

必要な場合:
```bash
source venv/bin/activate
pip install demucs
```

## 5. 使用方法クイックリファレンス

### 仮想環境の有効化

```bash
cd ~/projects/mir-tagger
source venv/bin/activate
```

### 単一ファイルの解析

```bash
python -m src.main "tests/samples/your_music.mp3"
```

### タグ書き込み（バックアップ付き）

```bash
python -m src.main "tests/samples/your_music.mp3" -w --backup
```

### 一括処理

```bash
# ドライラン
python batch_analyze.py /path/to/music/folder --dry-run

# 実行（4並列）
python batch_analyze.py /path/to/music/folder -w --backup -j 4
```

## 参考: 実行したコマンド履歴

```bash
# 1. リポジトリクローン
mkdir -p ~/projects
cd ~/projects
git clone https://github.com/Sota-Yamada-standard/mir-tagger.git

# 2. Homebrew パッケージ
brew install ffmpeg
brew install python@3.12
brew install cmake
brew install llvm@14

# 3. Python仮想環境
cd mir-tagger
/usr/local/bin/python3.12 -m venv venv
source venv/bin/activate
pip install --upgrade pip

# 4. Pythonパッケージ
pip install essentia mutagen numpy pyyaml tqdm

# 5. テストディレクトリ作成
mkdir -p tests/samples

# 6. 動作確認
python -m src.main -l
```
