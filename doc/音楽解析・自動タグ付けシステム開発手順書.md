音楽解析・自動タグ付けシステム開発手順書
プロジェクト概要
MIR（Music Information Retrieval）技術を活用し、ローカルの音楽ファイルを解析して「ジャンル」「楽器」「開始拍」などのメタデータを自動生成。最終的にrekordboxへ反映させるパイプラインを構築する。

1. 開発環境のセットアップ (Mac)
Cursorで以下のコマンドを実行し、環境を整えます。

• MIRライブラリのインストール:

  • `brew install essentia` (システムライブラリとして必要)

• Pythonライブラリのインストール:

  • `pip install essentia mutagen madmom librosa tensorflow`

2. 開発フェーズとタスク
フェーズ1：単体解析スクリプト (MVP)

1曲のファイルを読み込み、特徴量を抽出する。

• 目標: BPM、Key、Danceability、楽器構成（Synth/Guitar等）のスコア取得。

• 使用ツール: `essentia.standard`

フェーズ2：拍解析ロジック

「何拍目から始まるか」を判定するロジックの実装。

• 目標: ビートトラッキングを行い、最初の音のアタックと最初の1拍目（Downbeat）のオフセットを計算。

• 使用ツール: `madmom.features.beats`, `madmom.features.downbeats`

フェーズ3：メタデータ書き込み

解析結果を音楽ファイル自体に保存する。

• 目標: `Comment` 欄や `Grouping` 欄に、rekordboxが認識可能な形式で文字列（タグ）を書き込む。

• 使用ツール: `mutagen`

フェーズ4：一括処理とrekordbox連携

数千曲をスキャンし、一括で反映させる。

• 目標: マルチプロセスによる高速化、rekordbox XMLの生成またはタグ再読み込みフローの確立。

3. Cursorでのプロンプト指示例
CursorのAI（Claude 3.5 / GPT-4o）に以下のように指示を出して開発を進めてください。

• 解析コード作成時:

> 「Essentiaを使って、音声ファイルからBPM、Key、そして主要な楽器（ギター、シンセなど）を推定するPython関数を作成して。出力はJSON形式にしたい。」

• 拍解析の実装時:

> 「madmomライブラリを使って、曲の最初の1拍目の位置を特定し、曲の開始点から1拍目までの時間をミリ秒で出力するスクリプトを書いて。」

• タグ書き込み時:

> 「Mutagenを使用して、mp3ファイルのID3タグのComment欄に『[Genre: Techno][Start: Beat 1]』という形式で情報を追記するスクリプトを書いて。」

4. 注意点
• Essentiaのパス: MacのM1/M2チップの場合、ライブラリのパス指定に注意が必要です。

• バックアップ: 数千曲の一括書き換えを行う前に、必ず一部のファイルでテストを行ってください。
