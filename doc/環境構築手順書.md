# mir-tagger 環境構築手順書（Mac）

新しいMac環境でmir-taggerを動かすための手順です。

## 前提条件

- macOS（Apple Silicon / Intel）
- Homebrew がインストール済み
- Python 3.10以上
- Git がインストール済み
- Cursor エディタ

---

## 1. リポジトリのクローン

ターミナルまたはCursorのターミナルで実行：

```bash
# 作業ディレクトリへ移動
cd ~/projects  # 任意のディレクトリ

# リポジトリをクローン
git clone https://github.com/Sota-Yamada-standard/mir-tagger.git
cd mir-tagger
```

Cursorでフォルダを開く：
- `File` → `Open Folder...` → `mir-tagger` を選択

---

## 2. Python仮想環境のセットアップ

```bash
# 仮想環境を作成
python3 -m venv venv

# 仮想環境を有効化
source venv/bin/activate

# pipを最新化
pip install --upgrade pip
```

> 💡 Cursorのターミナルでも同様に実行できます

---

## 3. 依存パッケージのインストール

### 3.1 システムライブラリ（Homebrew）

```bash
# FFmpeg（音声処理に必要）
brew install ffmpeg
```

### 3.2 Pythonパッケージ

```bash
# 基本パッケージをインストール
pip install -r requirements.txt
```

> ⚠️ **注意**: demucsは重量級（約2GB）なので、必要になるまでスキップ可能です。
> 個別にインストールする場合：
> ```bash
> pip install essentia mutagen librosa numpy pyyaml tqdm
> ```

### 3.3 Apple Silicon（M1/M2/M3）での注意

- **Essentia**: ✅ pipで正常動作（arm64ネイティブ対応）
- **madmom**: インストール時にエラーが出る場合は以下を試す：
  ```bash
  pip install cython numpy
  pip install madmom
  ```
- **Demucs**: MPS（Metal Performance Shaders）加速対応あり

---

## 4. テスト用音楽ファイルの配置

`tests/samples/` ディレクトリはgitignoreされているため、手動で音楽ファイルを配置します：

```bash
# ディレクトリ作成（存在しない場合）
mkdir -p tests/samples

# 任意のMP3ファイルをコピー
cp /path/to/your/music.mp3 tests/samples/
```

---

## 5. 動作確認

### アナライザー一覧を表示

```bash
python -m src.main -l
```

期待される出力：
```
Available analyzers:
  - danceability: Analyzes danceability using Essentia
  - energy: Analyzes energy level using Essentia
  - key: Analyzes musical key using Essentia
```

### 単一ファイルを解析

```bash
python -m src.main "tests/samples/your_music.mp3"
```

期待される出力例：
```json
{
  "file": "your_music.mp3",
  "duration_sec": 240.5,
  "analysis": {
    "key": {"key": "C", "scale": "major", "strength": 0.85},
    "danceability": {"score": 1.2, "level": "High"},
    "energy": {"level": "High", "values": {...}}
  },
  "tags": "[Dance:High][Energy:High][Key:C]"
}
```

### タグを書き込み（バックアップ付き）

```bash
python -m src.main "tests/samples/your_music.mp3" -w --backup
```

---

## 6. 一括処理

複数ファイルを一括処理する場合：

```bash
# ドライラン（処理対象確認のみ）
python batch_analyze.py /path/to/music/folder --dry-run

# 解析 + タグ書き込み（4並列）
python batch_analyze.py /path/to/music/folder -w --backup -j 4
```

## トラブルシューティング

### `ModuleNotFoundError: No module named 'essentia'`

```bash
pip install essentia
```

### `ImportError: libsndfile not found`

```bash
brew install libsndfile
pip install --force-reinstall soundfile
```

### `madmom` インストールエラー

```bash
# Cython を先にインストール
pip install cython
pip install madmom
```

### Apple Silicon で `numpy` 関連エラー

```bash
pip install --upgrade numpy
```

## Cursor設定（推奨）

### Python Interpreter の設定

1. `Cmd + Shift + P` → `Python: Select Interpreter`
2. `./venv/bin/python` を選択

### 推奨拡張機能

- Python（Microsoft）
- Pylance

## ディレクトリ構成

```
mir-tagger/
├── doc/                    # ドキュメント
├── src/
│   ├── core/               # コアモジュール
│   │   ├── audio_loader.py
│   │   └── base_analyzer.py
│   ├── analyzers/          # プラグイン形式アナライザー
│   │   ├── key_analyzer.py
│   │   ├── danceability_analyzer.py
│   │   └── energy_analyzer.py
│   ├── metadata/
│   │   └── tag_writer.py
│   ├── export/             # (未実装)
│   ├── config.py
│   └── main.py             # CLIエントリポイント
├── tests/
│   └── samples/            # テスト用音楽ファイル（gitignore）
├── requirements.txt
├── batch_analyze.py        # 一括処理スクリプト
└── venv/                   # 仮想環境（gitignore）
```
