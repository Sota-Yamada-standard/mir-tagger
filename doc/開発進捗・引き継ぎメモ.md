## 📋 プロジェクト概要

MIR（Music Information Retrieval）技術を活用し、ローカルの音楽ファイルを解析して「ジャンル」「楽器」「開始拍」などのメタデータを自動生成。最終的にrekordboxへ反映させるパイプラインを構築する。

### ゴール
- 音楽ファイルを解析してタグを自動生成
- rekordboxのComment欄にタグを書き込み
- 後から拡張可能なプラグイン設計

## 🔧 使い方

### 単一ファイル解析
```bash
# JSON出力
python -m src.main "path/to/music.mp3"

# タグ形式出力
python -m src.main "path/to/music.mp3" -f tags

# 解析 + タグ書き込み（バックアップ付き）
python -m src.main "path/to/music.mp3" -w --backup
```

## 🔌 新しいアナライザーの追加方法

`src/analyzers/` に新しいファイルを作成するだけで自動登録される：

```python
# src/analyzers/my_analyzer.py
from src.core.base_analyzer import BaseAnalyzer, AnalyzerRegistry

@AnalyzerRegistry.register
class MyAnalyzer(BaseAnalyzer):
    name = "my_tag"
    description = "My custom analyzer"
    tag_prefix = "MyTag"
    
    def analyze(self, audio, sample_rate):
        # 解析ロジック
        return {'value': 'something'}
    
    def to_tag(self, result):
        return f"[{self.tag_prefix}:{result['value']}]"
```

## 📱 rekordbox連携について

### 確認済み事項
- **ID3タグ埋め込み方式を採用**（rekordbox.xml編集ではなく）
- Comment欄にタグを書き込む
- rekordboxで「情報を再読み込み」すると反映される
- **CUE/ビートグリッドは保持される**（再読み込みでは上書きされない）
- BPMはrekordboxの解析値をそのまま使う（上書きしない）

### マイタグについて
- rekordboxの「マイタグ」機能は外部から直接設定不可
- 代わりにComment欄を活用（検索可能）

## 🚀 今後のプラン（実装順序）

- Essentiaの特徴量 + 分類モデル
- または事前学習済みモデルの活用

- Downbeat検出（何拍目から始まるか）
- BPM変化検出（途中でテンポが変わる曲）
- madmomのインストールが必要

### ④ 音源分離（Demucs）+ 高度な検出
- ボーカル/ドラム/ベース/その他の分離
- 「歌で始まる」検出
- 「パーカッションのフィルインから始まる」検出
- 「途中でキメが入る」検出
- Demucsのインストールが必要（重量級）
