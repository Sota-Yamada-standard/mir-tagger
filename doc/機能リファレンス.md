## 概要

MIR-Taggerは音楽ファイルを解析し、DJ向けのタグを自動生成するツールです。生成されたタグはID3のComment欄に書き込まれ、rekordboxなどのDJソフトウェアで検索・フィルタリングに活用できます。

### 出力例

```
[Downbeat:1][Dance:High][Energy:VeryHigh][Genre:pop][Genre:anime][SpeechIntro:5s][MusicAt:5s][Key:Eb]
```

---

## タグ一覧

| タグ | 説明 | 値の例 |
|------|------|--------|
| `[Dance:X]` | 踊りやすさ | High, Medium, Low |
| `[Energy:X]` | エネルギーレベル | VeryHigh, High, Medium, Low |
| `[Key:X]` | 調（キー） | Am, Eb, F#m, etc. |
| `[Genre:X]` | ジャンル（複数可） | pop, rock, anime, techno, etc. |
| `[Attr:X]` | 属性（複数可） | vocal-female, vocal-male, dance, etc. |
| `[Mood:X]` | ムード（複数可） | happy, sad, relaxed, aggressive |
| `[Downbeat:X]` | 音楽が何拍目から開始 | 1, 2, 3, 4 |
| `[Meter:Irregular]` | 変拍子の可能性あり | Irregular（検出された場合のみ） |
| `[BPMChange:Yes]` | テンポ変化あり | Yes（変化がある場合のみ） |
| `[SpeechIntro:Xs]` | セリフイントロの長さ | 5s, 10s, etc. |
| `[MusicAt:Xs]` | 音楽開始位置 | 5s, 10s, etc. |
| `[Intro:X]` | イントロタイプ | Acapella, Singing, Vocal, Drums, Inst, Full |
| `[BeatAt:Xs]` | ビートが入るタイミング（静かなイントロ後） | 8s, 16s, etc. |

### 属性タグ `[Attr:X]` 一覧

属性タグは曲の特徴を示すもので、ジャンルとは別に出力されます。

| タグ | 説明 | 検出元 |
|------|------|--------|
| `[Attr:vocal-female]` | 女性ボーカルが主体 | MusiCNN |
| `[Attr:vocal-male]` | 男性ボーカルが主体 | MusiCNN |
| `[Attr:instrumental]` | インストゥルメンタル（ボーカルなし） | MusiCNN |
| `[Attr:guitar]` | ギターが目立つ | MusiCNN |
| `[Attr:dance]` | ダンサブルな曲 | MusiCNN |

**注意**: `[Attr:vocal]`（性別なし）は出力されません。ボーカルの性別が判定できない場合は属性タグが出力されないか、両方が出力されます。

#### パラメータ

```python
class GenreAnalyzer(BaseAnalyzer):
    name = "genre"
    description = "Genre classification (MusiCNN + PANNs + Essentia ensemble)"
    tag_prefix = "Genre"
    
    # 設定可能なパラメータ
    DEFAULT_THRESHOLD = 0.15    # ジャンル判定閾値
    MAX_GENRES = 3              # 最大出力ジャンル数
    
    MODEL_WEIGHTS = {
        'musicnn': 0.6,
        'panns': 0.2,
        'essentia': 0.2,
    }
```

#### カスタムルールの追加

```python
custom_rules = {
    "techno": {
        "conditions": {
            "bpm": (128, 145),
            "spectral_flatness_min": 0.15,
        },
        "score": 0.8
    }
}
analyzer = GenreAnalyzer(custom_rules=custom_rules)
```

#### 出力データ

```json
{
  "genres": [["pop", 0.21], ["anime", 0.18], ["j-pop", 0.16]],
  "primary_genre": "pop",
  "attributes": ["vocal-female"],
  "value": "pop"
}
```

### BeatAnalyzer

**ファイル**: `src/analyzers/beat_analyzer.py`

拍を解析します。Downbeat検出、BPM変化検出、変拍子検出、**セリフ自動スキップ**機能付き。

#### 出力タグ

| タグ | 説明 |
|------|------|
| `[Downbeat:1]` | 音楽が1拍目から開始 |
| `[Downbeat:2]` | 音楽が2拍目から開始 |
| `[Downbeat:3]` | 音楽が3拍目から開始 |
| `[Downbeat:4]` | 音楽が4拍目から開始 |
| `[Meter:Irregular]` | 変拍子の可能性あり |
| `[BPMChange:Yes]` | テンポが途中で変化（10 BPM以上の持続的変化） |

#### 特徴

- **セリフ自動スキップ**: PANNsでセリフ部分を検出し、音楽開始位置から分析
- **オンセット検出**: 音楽の正確な立ち上がりを検出
- **BPM変化検出**: 曲中のテンポ変化を検出（単発の揺らぎは除外）
- **変拍子検出**: ビート間隔の分布分析で4/4以外の拍子を検出

#### 変拍子検出の仕組み

変拍子（5/4、7/8など）の検出は、ビート間隔の分布を分析して行います：

1. ビート間隔の変動率を計算
2. ヒストグラムで複数の有意なピークを探す
3. ピーク間の比率が1.15〜1.85の場合、変拍子と判定

**注意**: 変拍子検出時はダウンビートの信頼度が低くなるため、`[Downbeat:X]`タグは出力されず、代わりに`[Meter:Irregular]`が出力されます。

#### パラメータ

```python
class BeatAnalyzer(BaseAnalyzer):
    name = "beat"
    description = "Beat analysis (downbeat, tempo changes, irregular meter, speech skip)"
    tag_prefix = "Beat"
    
    # 設定可能なパラメータ
    BPM_CHANGE_THRESHOLD = 10.0  # BPM変化検出閾値（持続的変化のみ）
    SPEECH_THRESHOLD = 0.3       # セリフ検出閾値
    MUSIC_THRESHOLD = 0.5        # 音楽検出閾値
    IRREGULAR_METER_THRESHOLD = 0.08  # 変拍子検出の変動率閾値
    
    def __init__(
        self,
        bpm_change_threshold: float = 10.0,
        auto_skip_speech: bool = True  # セリフ自動スキップ
    ):
```

#### 出力データ

```json
{
  "downbeat": 1,
  "first_beat_time": 0.859,
  "first_beat_time_absolute": 5.859,
  "music_start_time": 5.0,
  "tempo": 129.2,
  "tempo_stable": true,
  "tempo_changes": [],
  "irregular_meter": false,
  "meter_info": {
    "interval_variation": 0.025,
    "estimated_beats_per_bar": 4,
    "is_irregular": false
  },
  "beat_count": 490,
  "confidence": 0.98,
  "value": 1
}
```

### IntroAnalyzer

**ファイル**: `src/analyzers/intro_analyzer.py`

イントロを解析します。**Demucs音源分離** + **PANNsセリフ検出**のハイブリッド。

#### 出力タグ

| タグ | 説明 |
|------|------|
| `[SpeechIntro:5s]` | セリフが5秒間ある |
| `[MusicAt:5s]` | 音楽は5秒目から開始 |
| `[Intro:Acapella]` | アカペラ（伴奏なしボーカルソロ）で開始 |
| `[Intro:Singing]` | 伴奏付きで歌が始まる |
| `[Intro:Vocal]` | ボーカル入りで開始 |
| `[Intro:Drums]` | ドラムで開始 |
| `[Intro:Inst]` | インストで開始 |
| `[Intro:Full]` | フルバンドで開始 |
| `[BeatAt:8s]` | ビートが8秒目で入る（静かなイントロ後） |

#### セリフ vs ボーカルソロの区別

PANNsの異なるラベルを使用して区別します：

| 検出対象 | PANNsラベル | 判定条件 | 出力タグ |
|----------|-------------|----------|----------|
| **セリフ** | `Speech` | Speech > 0.3 かつ Music < 0.5 | `[SpeechIntro:Xs]` |
| **アカペラ** | `Singing` | Singing > 0.1 かつ Music < 0.5 かつ Speech < 0.3 | `[Intro:Acapella]` |
| **歌唱（伴奏あり）** | `Singing` + `Music` | Singing > 0.1 かつ Music ≥ 0.5 | `[Intro:Singing]` |

**例:**
- 「みんな抱きしめて銀河の果てまで！」（星間飛行）→ **セリフ** (Speech検出)
- アカペラで始まる曲 → **Singing** (Singing検出、Music低い)
- 伴奏と同時に歌が始まる曲 → **Vocal** (Singing + Music両方検出)

#### ビートドロップ検出

**「もう恋なんてしない」のように静かに始まって途中からビートが入る曲**を検出します。

| 検出条件 | 値 |
|----------|-----|
| 静かと判断するドラムエネルギー | < 0.03 |
| ドロップと判断する倍率 | 3倍以上 |
| 最低限の静かな時間 | 4秒以上 |
| 分析範囲 | 最初の60秒 |

**例:**
```
[Intro:Full][BeatAt:8s]  ← 静かに始まり、8秒目でビートが入る
```

**注意**: セリフイントロがある場合は `[MusicAt:Xs]` で音楽開始位置を表すため、`[BeatAt:Xs]` は出力されません。

#### 使用モデル

| モデル | 用途 |
|--------|------|
| Demucs (htdemucs) | 音源分離（vocals, drums, bass, other）、ビートドロップ検出 |
| PANNs | Speech/Music/Singing検出 |

#### パラメータ

```python
class IntroAnalyzer(BaseAnalyzer):
    name = "intro"
    description = "Intro analysis (speech, vocal, drums, beat drop detection)"
    tag_prefix = "Intro"
    
    # 設定可能なパラメータ
    SPEECH_THRESHOLD = 0.3      # セリフ判定閾値
    MUSIC_THRESHOLD = 0.5       # 音楽判定閾値
    SINGING_THRESHOLD = 0.1     # 歌唱判定閾値
    ENERGY_THRESHOLD_DRUMS = 0.05  # ドラム検出閾値
    ENERGY_THRESHOLD_VOCALS = 0.02 # ボーカル検出閾値
    
    # ビートドロップ検出
    BEAT_DROP_LOW_THRESHOLD = 0.03   # 静かと判断する閾値
    BEAT_DROP_HIGH_RATIO = 3.0       # ドロップ判定倍率
    BEAT_DROP_MIN_QUIET_TIME = 4.0   # 最低限の静かな時間
    BEAT_DROP_ANALYSIS_DURATION = 60 # 分析範囲（秒）
    
    ANALYSIS_DURATION = 15      # 分析する秒数
    CHUNK_DURATION = 1.0        # 分析チャンクサイズ
    
    def __init__(
        self,
        analysis_duration: float = 15,
        chunk_duration: float = 1.0,
        device: str = "auto"  # "auto", "mps", "cpu"
    ):
```

### MoodAnalyzer

**ファイル**: `src/analyzers/mood_analyzer.py`

ムードを解析します。**Essentiaのムード専用モデル**を使用した高精度検出。

#### 出力タグ

| タグ | 説明 |
|------|------|
| `[Mood:happy]` | 明るい、楽しい |
| `[Mood:sad]` | 切ない、悲しい |
| `[Mood:relaxed]` | 穏やか、リラックス |
| `[Mood:aggressive]` | 激しい、攻撃的 |

**複数検出**: 複合的な感情を持つ曲は複数のムードタグが出力されます。

```
[Mood:relaxed][Mood:happy][Mood:sad]
```

#### 使用モデル

| モデル | 精度 |
|--------|------|
| mood_happy-msd-musicnn-1.pb | 84% |
| mood_sad-msd-musicnn-1.pb | - |
| mood_relaxed-msd-musicnn-1.pb | - |
| mood_aggressive-msd-musicnn-1.pb | - |

#### 閾値ロジック

1. **MOOD_THRESHOLD (0.75)** を超えるもの全て出力
2. 閾値を超えるものがなければ、**MIN_CONFIDENCE (0.5)** 以上の最高スコアを出力
3. 全て0.5未満ならムードタグなし

#### パラメータ

```python
class MoodAnalyzer(BaseAnalyzer):
    name = "mood"
    description = "Mood analysis using Essentia TensorFlow models"
    tag_prefix = "Mood"
    
    MOOD_THRESHOLD = 0.75    # 特徴的なムードの閾値
    MIN_CONFIDENCE = 0.5     # 最低限の自信度
    
    def __init__(
        self,
        mood_threshold: float = 0.75,
        min_confidence: float = 0.5,
        models_dir: str = None
    ):
```

#### 出力データ

```json
{
  "moods": {"happy": 0.935, "sad": 0.860, "relaxed": 0.957, "aggressive": 0.237},
  "detected_moods": ["relaxed", "happy", "sad"],
  "primary_mood": "relaxed",
  "value": "relaxed"
}
```

## カスタマイズ

### カスタムジャンルルールの追加

`src/analyzers/genre_analyzer.py` の `ESSENTIA_RULES` に追加：

```python
ESSENTIA_RULES = {
    "my-genre": {
        "conditions": {
            "bpm": (120, 140),           # BPM範囲
            "spectral_centroid": (2000, 4000),  # 周波数特性
            "beats_confidence_min": 2.0,  # ビート信頼度
        },
        "boost": 0.8,  # スコアブースト
    },
}
```

### 閾値の調整

各アナライザーのクラス変数または `__init__` パラメータで調整可能：

```python
# ジャンル検出の閾値を下げる（より多くのジャンルを検出）
analyzer = GenreAnalyzer(threshold=0.1, max_genres=5)

# セリフスキップを無効化
analyzer = BeatAnalyzer(auto_skip_speech=False)

# MPS（GPU）を使用
analyzer = IntroAnalyzer(device="mps")
```
